WEBENG v1.0

Browser Game Value Modifier Engine

Value Scanner

Cheat Engine-style first scan / next scan workflow to find and narrow down in-game values like money, health, and items.

Value Modifier

Change any discovered value instantly. Freeze values so they persist even when the game tries to update them.

Network Interceptor

Intercept and modify XHR, Fetch, and WebSocket traffic with regex-based rules. Change server responses on the fly.

Anti-Tamper Bypass

Bypass Object.freeze, read-only properties, and integrity-check timers. Stay hidden from detection scripts.

Quick Start

Method 1: Console Paste (Recommended)

  1. Open the game in your browser
  2. Open DevTools (F12 or Ctrl+Shift+I)
  3. Go to the Console tab
  4. Copy the contents of dist/webeng.js and paste into the console
  5. Press Enter — the WebEng panel appears!

How to Use

Scanning for Values

1. Note the current value in the game (e.g., gold = 500)
2. Enter "500" in the Scanner tab and click "First Scan"
3. Do something in the game to change the value (e.g., spend gold)
4. Enter the new value and click "Next Scan"
5. Repeat until only a few results remain
6. Click "Edit" to change the value, or "Freeze" to lock it

Network Interception

1. Go to the Network tab and watch requests flow in
2. Click "Rules" sub-tab, then "+ New Rule"
3. Set a URL pattern to match the game's API endpoints
4. Define find/replace patterns for response bodies
   Example: Find: "gold":100  Replace: "gold":999999
5. The rule automatically modifies matching responses

Console API

// Scan for a value
__WEBENG__.scan(500)

// Narrow results after the value changes
__WEBENG__.nextScan(450)

// Set a value directly (if you know the path)
__WEBENG__.set('window.game.player.gold', 999999)

// Freeze a value (re-applied every 50ms)
__WEBENG__.freeze('window.game.player.health', 100)

// Add a network modification rule
__WEBENG__.addRule({
  name: 'Infinite Gold',
  urlPattern: '.*api/save.*',
  target: 'response',
  find: '"gold":\\d+',
  replace: '"gold":999999'
})

// Create a writable proxy for a frozen config object
window.game.config = __WEBENG__.unfreezeObj(window.game.config)
